Install And Run

  1. Install a local model runner such as Ollama, LM Studio, or llama.cpp server.
  2. Start its local server. Ollama usually listens at http://127.0.0.1:11434; LM Studio commonly exposes an OpenAI-compatible /v1 server.
  3. For Ollama, allow this extension origin with OLLAMA_ORIGINS. Pinning the exact extension is safer than allowing every browser extension. The Copy Launch Command button can include this automatically.
  4. Download a small model in that app. For Ollama, copy a pull command below and run it in a terminal.
  5. Put the exact model name and base URL into ylang settings, save, then run checks again.

Ollama's FAQ says browser extension origins can be allowed with broad patterns like chrome-extension://*, or with specific extensions. Prefer the specific origin shown below.

Chrome extensions cannot directly launch local executables or scripts. The launch command field is stored so you can copy it now, and so a future native helper can use it.

Chrome/Edge: open chrome://extensions or edge://extensions, enable Developer mode, find ylang, and copy its ID if this page cannot detect it. Keep Ollama local with OLLAMA_HOST=127.0.0.1:11434 and avoid OLLAMA_HOST=0.0.0.0:11434 plus OLLAMA_ORIGINS=* unless you intentionally want network exposure.
With the checkbox enabled, Copy Launch Command uses PowerShell syntax: $env:OLLAMA_HOST='127.0.0.1:11434'; $env:OLLAMA_ORIGINS='chrome-extension://...'; ollama serve. In bash/zsh, use OLLAMA_HOST=127.0.0.1:11434 OLLAMA_ORIGINS=chrome-extension://... ollama serve.
setx stores the values for future terminals. After running it, close and reopen the terminal before starting Ollama.
